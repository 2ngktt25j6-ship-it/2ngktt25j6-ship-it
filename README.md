# 介護福祉士試験対策ラジオ（試作）
GitHub Actions + VOICEVOX + FFmpeg で日本語の会話動画（MP4）を作る無料枠検証用プロジェクトです。

## 使い方
1. `dialogue.json` のセリフを編集します。
2. Actions > 「介護ラジオ MP4生成」 > Run workflow を実行します。
3. 実行完了後、該当runの Artifacts から `care-radio-mp4` を取得します。

## 注意
- GitHub Actions の無料利用条件はアカウント・リポジトリ公開設定・利用量により異なります。費用ゼロは実行前に確認してください。
- 音声はVOICEVOXのずんだもん（speaker=3）と四国めたん（speaker=2）を使用する暫定版です。声の性別・キャラクターの最終設定は別途調整します。
- 公開動画にはVOICEVOXおよび使用音声ライブラリの利用規約に従ったクレジット表記をしてください。
- 現段階は静止画字幕＋音声のMP4であり、以前のキャラクターマスター画像はまだ組み込んでいません。
- 動作未検証の初期構成です。初回実行結果を確認して調整します。
